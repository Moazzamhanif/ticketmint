# TicketMint Pages files

Upload these three files to the root of a new public GitHub repository named `ticketmint`, then enable GitHub Pages from the `main` branch and `/ (root)`.

Expected page paths after Pages finishes deploying:
- `https://YOUR-USERNAME.github.io/ticketmint/privacy.html`
- `https://YOUR-USERNAME.github.io/ticketmint/support.html`

Replace every bracketed placeholder in `privacy.html` and `support.html` with confirmed details before using these pages in App Store Connect. The current files are drafts and are not ready to be represented as a final privacy policy.
